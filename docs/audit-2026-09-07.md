# Orion — system audit (2026-09-07)

Full audit of the one-node deployment (egress node, AmneziaWG + Tor + kill
switch) and the desktop client, after the first week of daily use. Findings
are ordered by severity; every CRITICAL and HIGH item was fixed the same day.

## Findings

| ID | Severity | Area | Finding | Status |
|---|---|---|---|---|
| F1 | CRITICAL | client | Tray init panicked at startup when `libappindicator` was absent (menu launches aborted instantly — "Orion doesn't open") | **fixed** — catch_unwind guard, degrades to no-tray; library installed |
| F2 | CRITICAL | client | UI state-machine deadlock: `poll()` skipped derivation while `phase === "linking"` and nothing cleared the flag after connect resolved — app stuck on "Connecting…" forever while the tunnel was actually up | **fixed** — connecting is a separate flag; watchdogs (UI 30 s, helper timeouts 25/10 s) |
| F3 | HIGH | client | XSS vector: server list built with `innerHTML` including city strings from a third-party geolocation API | **fixed** — DOM APIs + `textContent` only |
| F4 | HIGH | client | Profiles could carry `PostUp`/`PreUp`/`PostDown`/`PreDown`/`Table` lines — wg-quick/awg-quick executes them as root | **fixed** — helper strips all exec hooks; audit-diffed against upstream wg-quick behavior |
| F5 | HIGH | node | Ghost prerouting redirect captured ALL ghost TCP — including the Tor control port, so control connections were force-redirected into the SOCKS port and reset | **fixed** — `dport != 9051` exemption; control flow verified end-to-end (NEWNYM accepted, exit rotated) |
| F6 | MEDIUM | host env | UFW default-deny (routed) blocks Docker containers' DNS while the tunnel is up | **mitigated** — `ufw route allow in on docker0 out on orion0` applied on the user's machine |
| F7 | MEDIUM | client | Settings modal could not be closed — `display: flex` on the backdrop overrode the `hidden` attribute | **fixed** — `[hidden] { display: none }` rule; Escape and backdrop-click close |
| F8 | MEDIUM | client | `awg-quick` config search path differs from wg-quick — AWG profiles failed with "config does not exist" | **fixed** — helper writes to the AWG search path |
| F9 | LOW | repo | First public push briefly contained the live node IP in AGENTS.md and phase docs | **scrubbed** — history force-pushed (single-commit repo); optional: recreate the droplet for a fresh IP |
| F10 | LOW | client | PAT stored in plaintext at `~/.git-credentials` (standard git store) | **documented** — fine-grained token, minimal scope; rotate after setup if desired |
| F11 | INFO | node | UFW blocks forwarded container DNS by default when the tunnel is down | documented — containers use the normal WAN path when Orion is off |

## Verified invariants (re-tested after fixes)

- Handshake completes in ~1 s through the obfuscated tunnel; Fast exit = node
  IP; Ghost exit = Tor relay (rotation confirmed via NEWNYM: Amsterdam →
  Alkmaar).
- Kill-switch table survives helper crashes; intentional disconnect is the
  only clean path; failed bring-up rolls the lock back.
- DNS cannot bypass the tunnel for Ghost peers (redirect to Tor DNSPort);
  QUIC/443-UDP and IPv6 are dropped on the egress path.
- Helper drops `PostUp`-family lines and strips DNS when no resolvconf hook
  exists; node logs are volatile; SSH is key-only on port 2222.

## Open items (by design, not defects)

- Entry-node chaining: fully staged, awaiting a second droplet
  ([docs/phase-4.md](phase-4.md)).
- Native Windows/macOS tunnel helpers: design spec at
  [platform-helpers.md](platform-helpers.md); Linux is the supported platform
  today and the win/mac CI jobs produce UI shell builds.
- CI does not bundle the AppImage (linuxdeploy quirk on runners); the deb is
  the release artifact and the AppImage is built locally with
  `NO_STRIP=1 APPIMAGE_EXTRACT_AND_RUN=1 npx @tauri-apps/cli@2 build`.
